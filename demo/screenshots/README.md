# `demo/screenshots/`

Screenshots for [DEMO.md](../../DEMO.md#screenshots). The list of files, and which step uses each one, is in DEMO.md.

- **Names:** `NN-short-name.png`, a two-digit step order and a kebab-case name, exactly as listed in DEMO.md.
- **Format:** PNG, about 1600 px wide, cropped to the relevant part. Use light mode for terminals and dashboards, so the images match GitHub's default.
- **Redact before committing** (this repository is public):
  - your own IP addresses (the scraper's and the visitor's);
  - email addresses and Discord user IDs;
  - Access team domain, application AUD tag and service token Client IDs;
  - account and zone IDs, and Worker or Workflow instance IDs that include them.

  The demo hostnames and Ray IDs are fine to keep.
